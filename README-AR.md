# UniAtlas — أطلس جامعتك

> **جامعتك… على الخريطة.**
>
> تجربة طالب عربية (RTL) تبدأ بخريطة العالم لاختيار الجامعة، و**UniBg** هي الجامعة المتاحة بالكامل الآن. باقي الجامعات تظهر كـ«قريباً» ويقدر الطالب يسجّل اهتمامه بيها.

## ٣. الأقسام

1. **الرئيسية** — ملخص سريع لكل حاجة.
2. **الخريطة التفاعلية** — خريطة مقرات UniBg ومبانيها.
3. **دليل المباني** — بحث وفلترة حسب النوع والمقر.
4. **المسار الأكاديمي** — مواد، CFU، وحالة كل مادة.
5. **دليل الإجراءات** — Permesso، Codice Fiscale، ISEE… خطوة بخطوة.
6. **بنك الأسئلة** — أسئلة شفهية، بروفيسورات، وبطاقات مراجعة.
7. **المجتمع والحياة** — مجموعات، فعاليات، لوحة نقاش بالردود، تجارب وحلول، خصومات، ومواصلات.
8. **السكن والغرف** — خيارات تجريبية مع حفظ ومقارنة وتفاصيل.
9. **المنح والرسوم** — حاسبة ISEE تقريبية، شرائح الرسوم، ومنحة DSU.
10. **التدريب والوظائف** — فرص تجريبية، حفظ، وتفاصيل + قائمة تجهيز CV.
11. **مساحتي** — كل المحفوظات، الاهتمامات، المساهمات، والاقتراحات في مكان واحد.

### المجتمع والحياة — تفاصيل

- **مجموعات الطلاب** — انضم لمجموعة موجودة أو أنشئ مجموعة جديدة (مذاكرة، لغة، رياضة…) وحدد المقر والموعد وعدد الأماكن.
- **الفعاليات** — فلترة حسب النوع، تسجيل حضور، وإضافة الموعد للتقويم بصيغة `.ics`.
- **لوحة المجتمع** — منشورات بأسئلة وتوصيات، وردود مباشرة على كل منشور.
- **تجارب وحلول** — شارك مشكلة حقيقية وإزاي حليتها، مع تصنيفات وتصويت «مفيد» وحذف لتجاربك.
- **الحياة اليومية** — أماكن وخدمات، خصومات بأكواد، ومواصلات.

## ٤. تركيب البلجن على ووردبريس

### الطريقة السريعة

1. من لوحة ووردبريس: **بلجنات ← أضف جديد ← رفع بلجن**.
2. ارفع ملف `uniatlas.zip`.
3. اضغط **تفعيل**.
4. البلجن هينشئ صفحة اسمها **UniAtlas** فيها الشورت كود `[uniatlas]` تلقائياً.
5. افتح الصفحة — هتلاقي الخريطة أول حاجة.

### لو الصفحة مش موجودة

أنشئ صفحة جديدة وضع فيها:

```text
[uniatlas]
```

الشورت كود القديم `[unibg_super_app]` شغال برضه.

### قالب ملء الشاشة

البلجن بيستخدم قالب `templates/fullscreen.php` تلقائياً لصفحة التطبيق عشان يظهر بدون هيدر/فوتر القالب. تقدر تطفّي الخيار من **UniAtlas ← الإعدادات**.

لو عايز أي صفحة تانية تاخد نفس القالب: من محرر الصفحة فعّل خيار **«استخدم قالب UniAtlas بملء الشاشة»** في الصندوق الجانبي.

## ٥. مدير الجامعات (إضافة جامعة واحدة في كل مرة)

من لوحة ووردبريس: **UniAtlas ← مدير الجامعات**.

املأ بيانات الجامعة:

- الاسم بالإنجليزي (مطلوب)
- الاسم المختصر
- الاسم بالعربي
- المدينة والدولة
- العلم (إيموجي)
- خط العرض وخط الطول (من خرائط جوجل: كليك يمين ← What's here?)
- سنة التأسيس، عدد الطلاب، عدد البرامج
- جملة تعريفية ووصف مختصر
- أبرز المزايا (حتى ٤، مفصولة بفاصلة)
- الموقع الرسمي
- لون التمييز
- عدد المهتمين الافتراضي
- موعد الإطلاق المتوقع

الجامعة بتظهر فوراً على الخريطة كـ«قريباً»، والطلاب يقدرون يسجلوا اهتمامهم. البيانات بتتخزن في خيار ووردبريس `uniatlas_universities` وبتتبعت للواجهة عبر `window.UniAtlasData.universities`.

> **ملاحظة:** التجربة الكاملة (مباني، مواد، إجراءات…) مبنية حالياً لـ UniBg فقط. أي جامعة جديدة تظهر كبطاقة تعريفية واهتمام لحد ما يتم تجهيز محتواها.

## ٦. إضافة جامعة من الكود (تجربة كاملة)

افتح `src/app.js` وابحث عن `var UNIVERSITIES = [`، وأضف عنصر جديد بنفس الشكل:

```js
{
  id: "padova",
  name: "University of Padova",
  short: "UniPD",
  ar: "جامعة بادوفا",
  city: "بادوفا",
  cityIt: "Padova",
  country: "إيطاليا",
  countryIt: "Italia",
  flag: "🇮🇹",
  coords: [45.4064, 11.8768],
  status: "coming", // أو live لما المحتوى يجهز
  established: 1222,
  students: "~60,000",
  programs: "180+",
  tagline: "مدينة جامعية عريقة… وقريبة من فينيسيا.",
  blurb: "وصف مختصر للطلاب.",
  highlights: ["مدينة جامعية", "برامج إنجليزية", "منح إقليمية"],
  official: "https://www.unipd.it",
  accent: "#7c5cff",
  baseInterest: 0,
  eta: "قريباً · 2028"
}
```

بعدها:

```bash
node build.js
```

البناء هيعيد توليد `preview.html` وملفات البلجن. لو الجامعة `live`، هتفتح تجربة UniBg الحالية — فالأفضل تسيبها `coming` لحد ما تبني محتواها.

## ٧. التشغيل والمعاينة

### معاينة مباشرة

افتح `preview.html` في المتصفح. محتاج إنترنت لـ:

- Leaflet من jsDelivr
- خرائط Esri
- خطوط Google Fonts

### سيرفر محلي (اختياري)

```bash
npx serve .
```

أو أي سيرفر ثابت، وبعدها افتح `http://localhost:3000/preview.html`.

### إعادة البناء

```bash
node build.js
```

مفيش Dependencies ومفيش Build tooling — Node بس.

## ٨. الخصوصية والبيانات

- كل تفضيلات الطالب (الاسم، المقر، التخصص، المواد، المفضلة، السكن المحفوظ، الوظائف المحفوظة، الاهتمامات، الاقتراحات، XP، المجموعات المنشأة، المنشورات، الردود، التجارب، التصويتات، والعروض المحفوظة) بتتخزن في **localStorage** في متصفح الزائر.
- مفيش أي بيانات بتتبعت لسيرفر.
- مفتاح التخزين: `uniatlasState.v2`، مع ترحيل تلقائي من `uniatlasState.v1` و`unibgHubState.v1`.
- زر **«صدّر بياناتك»** في مساحتي بينزّل ملف JSON.
- زر **«صفّر التجربة»** بيمسح البيانات المحلية ويرجّع الواجهة لحالتها الأولى.
